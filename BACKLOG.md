### P0 — Must have
- [ ] **Delete items** — swipe-to-delete or long-press delete on shopping items
- [ ] **Edit items** — tap to edit name, quantity, category
- [ ] **Leave group** — option to leave a group (removes from member list)

### P1 — Should have
- [ ] **Item suggestions** — autocomplete from previously added items when typing
- [ ] **Push notifications** — notify when someone adds an item (via Firebase Cloud Messaging)
- [ ] **Dark/light theme toggle** — respect system theme or manual toggle

### P2 — Nice to have
- [ ] **Order history** — show items marked "Bought" grouped by date
- [ ] **Expense tracking** — rough cost estimates per item, split summary
- [ ] **Multiple lists per group** — e.g. "Weekly Groceries", "Party Supplies"
- [ ] **Profile avatars** — pick an emoji/color avatar per user
- [ ] **Share via WhatsApp** — direct share button for invite code
